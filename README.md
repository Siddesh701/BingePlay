# 🎬 BingePlay

BingePlay is a database-driven streaming platform project 
designed to manage users, subscriptions, shows, 
watch history, and ratings.

## Features
- User Management
- Subscription Management
- Shows Management
- Watch Session Tracking
- Ratings System

## Technologies
- MySQL
- SQL
- VS Code
- Git & GitHub

## Database Tables
- users
- subscriptions
- shows
- watch_sessions
- ratings

## Project Status
Database design and SQL table creation completed.

- Backend integration
- Authentication
- Movie and show browsing
- Subscription management
